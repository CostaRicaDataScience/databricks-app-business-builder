## 9. How to start development (with OmniAgent)

The project skeleton lives at `out/databricks-app-business-builder/`. Follow these steps to start
building it with OmniAgent.

1. **Review the generated repo**
   - Living architecture: `out/databricks-app-business-builder/docs/blueprint.md`
   - Design + module map: `out/databricks-app-business-builder/docs/design.md`
   - Gaps, risks, tech debt: `out/databricks-app-business-builder/docs/gapmaster.md`
   - Contracts to honor: `out/databricks-app-business-builder/contracts/base-contracts.yaml`

2. **Turn it into its own repository**
   ```bash
   cd out/databricks-app-business-builder
   git init && git add -A && git commit -m "chore: bootstrap Databricks App business builder"
   ```

3. **Tell OmniAgent the repo exists and start working in it**
   - Point an Omnigent coding agent at the new repo (its `os_env.cwd` is the
     repo root, so the agent reads/writes there):
   ```bash
   cd out/databricks-app-business-builder
   omnigent claude        # or: omnigent codex / omnigent run <your-agent>.yaml
   ```
   - Or drive it from the bootstrapper supervisor, which already knows the
     phase flow and specialists:
   ```bash
   omnigent run agents/bootstrapper/supervisor.yaml \
     -p "Implement the MVP for Databricks App business builder in out/databricks-app-business-builder following docs/blueprint.md"
   ```

4. **Install dependencies (per the normalized manifest)**
   ```bash
   # config/dependencies.yaml lists the pinned, license-checked libraries
   uv venv && source .venv/bin/activate
   uv pip install <libraries from config/dependencies.yaml>
   ```

5. **Implement module by module, honoring the contracts**
   - Start with `modules/core` (ConfigProvider, Logger), then `modules/domain`,
     `modules/app` (UseCase), and `modules/infra` (Repository).
   - Each `agents/<function>__<role>/agent.yaml` is a stub you can flesh out
     and run with `omnigent run`.

6. **Use a persistent multi-phase session (optional)**
   ```bash
   ops/tmux/bootstrapper.session.sh    # one tmux window per phase/specialist
   ```

7. **Evolve the blueprint as you learn** (it is mutable + versioned)
   ```bash
   bootstrapper blueprint evolve databricks-app-business-builder \
     --change "Describe what changed" --rationale "Why"
   ```
